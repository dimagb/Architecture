# Проекты по АСОИУ

Стек: C#, SQLite, EF Core, LINQ, ASP.NET Core MVC, HTML5, CSS3

Приложение с серверной БД. Разработано:

1. Модель данных
• Класс-модель для справочной таблицы (master) с навигационным свойством-коллекцией.

• Класс-модель для основной таблицы (detail) с навигационным свойством- ссылкой на справочник.

• Класс AppDbContext, наследующий от DbContext, с двумя DbSet<T>

• Автоматическое создание БД при первом запуске (EnsureCreated)

• Заполнение начальными данными при пустой БД.

2. Форма / контроллер справочной таблицы (master)
• Просмотр — список всех записей справочника

• Добавление — форма/страница ввода новой записи

• Редактирование — форма/страница изменения существующей записи

• Удаление — с подтверждением; запрет удаления, если есть связанные записи в основной таблице

3. Форма / контроллер основной таблицы (detail)
• Просмотр — список всех записей с отображением названия категории из справочника (через Include).

• Добавление — форма/страница; категория выбирается из выпадающего списка.

• Редактирование — форма/страница; категория выбирается из выпадающего списка.

• Удаление — с подтверждением.

• Валидация числового поля: значение не может быть отрицательным.

4. Форма / контроллер отчёта
• Раздел 1. Полный список записей основной таблицы с названием категории (LINQ: Include + OrderBy)

• Раздел 2. Количество записей по категориям (LINQ: GroupBy + Count)

• Раздел 3. Среднее значение числового поля по категориям, сортировка по убыванию (LINQ: GroupBy + Average + OrderByDescending)

5. Навигация
Главное окно / меню / навигационная панель с переходом ко всем трём разделам приложения.

6. Требования к качеству кода
Все публичные классы и их публичные члены снабжены XML- комментариями.
